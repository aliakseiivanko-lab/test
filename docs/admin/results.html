Результаты учеников

Страница для учителя. Ученикам она не нужна: без токена она пустая.
Как получить токен (один раз)
  1. GitHub → ваш аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: например «просмотр результатов». Expiration: например, 1 год.
  3. Repository access → Only select repositories → выберите репозиторий с результатами (result).
  4. Permissions → Repository permissions → Issues: Read-only (достаточно чтения, записывать ничего не нужно).
  5. Generate token → скопируйте токен (он показывается один раз) и вставьте выше. Это другой токен, не тот, что в Cloudflare.
