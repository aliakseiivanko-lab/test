Как получить токен (один раз)
  1. Войдите на github.com → ваш аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: любое (например «tests»). Expiration: выберите срок (например, 1 год).
  3. Repository access → Only select repositories → выберите репозиторий с этим сайтом.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token → скопируйте токен (он показывается один раз) и вставьте выше. Сохраните его в надёжном месте (менеджер паролей).
