ТЕСТЫ ДЛЯ УЧЕНИКОВ НА GITHUB PAGES (без установки программ)
===========================================================

ЧТО ЭТО
- Сайт для детей: https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/
  Класс -> тест -> сразу 5 случайных вопросов -> видно, какие верно, а какие неверно (правильные ответы
  не показываются). Всегда включён, результаты нигде не сохраняются.
- Админка для вас: https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/admin/
  Работает в браузере на ЛЮБОМ компьютере: загрузить, заменить, скачать, удалить тест, изменить число
  вопросов. Ничего устанавливать не нужно. Изменения попадают на сайт через 1-2 минуты.

ПЕРВАЯ НАСТРОЙКА (один раз, всё в браузере)
1. Распакуйте этот архив. Войдите (или зарегистрируйтесь) на github.com.
2. Нажмите «+» -> New repository. Имя, например, tests. Выберите Public -> Create repository.
3. В новом репозитории: «uploading an existing file» (или Add file -> Upload files).
   Перетащите в окно ДВЕ папки из распакованного архива: docs и tests_src. Дождитесь загрузки,
   внизу нажмите Commit changes.
4. Settings -> Pages -> Build and deployment: Source = «Deploy from a branch»,
   Branch = main, папка = /docs -> Save. Через 1-2 минуты сайт откроется (адрес покажет эта же страница).
5. Токен доступа (нужен админке, чтобы сохранять тесты в ваш репозиторий):
   github.com -> ваш аватар -> Settings -> Developer settings -> Personal access tokens ->
   Fine-grained tokens -> Generate new token.
     - Token name: любое. Expiration: например, 1 год.
     - Repository access: Only select repositories -> выберите репозиторий с тестами.
     - Permissions -> Repository permissions -> Contents: Read and write.
     - Generate token. Скопируйте токен (показывается один раз) и сохраните в менеджере паролей.
6. Откройте админку (.../admin/), введите «ЛОГИН/РЕПОЗИТОРИЙ» и токен -> Войти.

РАБОТА С ТЕСТАМИ
- Загрузка: «Скачать шаблон» -> заполните Excel (инструкция на первом листе) -> выберите файл.
  Для картинок: положите Excel и картинки в один ZIP. Можно загрузить сразу несколько файлов
  или один ZIP с несколькими тестами. Перед сохранением админка покажет ошибки по строкам.
- Если тест с таким названием уже есть, предложит «Заменить» (иначе - «Добавить как новый»).
- Исправить тест: в списке «Скачать» -> измените в Excel -> загрузите снова и выберите «Заменить».
- «Просмотр» показывает вопросы и правильные ответы. «Удалить» убирает тест с сайта.
- «Вопросов у ученика в каждом тесте» - по умолчанию 5.
- Тест показывается ученикам на вкладке своего класса (поле «Классы» в Excel: 7, 5-7, 7, 8).

БЕЗОПАСНОСТЬ
- Токен - это ключ к вашему репозиторию. Не отправляйте его другим. «Запомнить на этом компьютере»
  отмечайте только на своём. На чужом компьютере нажмите «Выйти» после работы. Если токен потерян -
  удалите его на GitHub (Settings -> Developer settings) и создайте новый.
- Адрес админки открыт всем, но без токена ничего изменить нельзя.
- Репозиторий должен быть Public (бесплатные Pages). Поэтому файл tests_src/tests.json с правильными
  ответами открытым текстом виден всем, кто найдёт репозиторий. В файле для сайта (docs/tests.json)
  ответы хранятся хешами: обычный ученик их не прочитает, опытный сможет подобрать. Для тренировки
  и самопроверки это нормально, для оцениваемых контрольных - нет.

СТРУКТУРА РЕПОЗИТОРИЯ
docs/index.html      сайт для учеников
docs/admin/          админка (index.html) и шаблон Excel
docs/tests.json      тесты для сайта (создаётся админкой)
docs/img/            картинки к вопросам (создаются админкой)
tests_src/tests.json исходные тесты с ответами (создаётся админкой)
