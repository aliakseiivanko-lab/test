Картинки и файлы
Пути пишутся как в обычном HTML — относительно файла: img/cat.png, ../style.css, /logo.svg (от корня папки). Если «Выбрать» не даёт выбрать папку (например, «Загрузки»), нажмите «Через список» или перетащите папку на страницу. Картинки, CSS и JS подтягиваются из папки сами, даже если путь написан не точно: ищется файл с таким именем. После выбора папки редактор берёт картинки, CSS и JS оттуда, а «Сохранить» записывает файл в эту же папку. Без папки (новый сайт) относительные пути работать не будут. 

    
Введите ! и нажмите Tab (или ⇥ Emmet) — появится разметка. CSS и JS пишите прямо в тегах <style> и <script>. Примеры: ul>li*3, div.box#a, a[href=#]{Ссылка}
